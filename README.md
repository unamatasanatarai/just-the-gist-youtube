# Just the Gist — YouTube

**Turn any YouTube video into a clean English brief in one command: TL;DR, key points, quotes and topics, saved as Markdown.**

Paste a link and get back what the video actually says, without watching it. Just the Gist pulls the video's captions, hands them to Google Gemini and writes a structured summary you can read in a minute and keep for later. It works with captions in any language, and the summary always comes back in English.

## Why Just the Gist

Long videos hide a few minutes of real content. Auto-generated captions are unpunctuated, full of `[Music]` and filler, and often in another language.

Just the Gist turns that into a summary that has the same shape every time, with nothing made up. Gemini is told to base everything only on the transcript and to skip caption noise. You get a Markdown file you can skim, search, diff or drop into your notes.

## What You Get

Real output, saved to `summaries/rick-astley-never-gonna-give-you-up-official-video-4k-remaster.md`:

> # Rick Astley - Never Gonna Give You Up (Official Video) (4K Remaster)
>
> Rick Astley · 3:33 · https://www.youtube.com/watch?v=dQw4w9WgXcQ
>
> > **TL;DR** Rick Astley performs his classic pop anthem assuring his partner of his unwavering commitment and loyalty.
>
> ## Key points
>
> - The singer and his partner are well-acquainted with the rules of love.
> - A full commitment is explicitly promised.
> - The singer vows never to give up or let the partner down.
>
> ## Topics
>
> Pop Music · Music Video · 1980s Music · Romance · Rick Astley
>
> ---
> Generated by gemini-3.5-flash-lite from transcriptions/rick-astley-…txt on 2026-10-28

Every summary has the same five parts:

| Section | What it contains |
| --- | --- |
| **TL;DR** | The main point in one sentence |
| **Summary** | 2–4 paragraphs on what the video covers |
| **Key points** | 5–10 takeaways, in the order they appear |
| **Notable quotes** | Short quotes worth remembering, translated to English if needed |
| **Topics** | 3–8 short tags |

## Key Features

### Any video link works
Paste a `watch?v=`, `youtu.be/`, `shorts/`, `embed/` or `live/` URL, a `m.` or `music.` link, or a bare 11-character video ID. Tracking parameters like `?si=` are ignored.

### Picks the best captions for you
Captions are chosen in this order: manual English, auto-generated English, the video's original language (manual, then auto), then any other manual track. YouTube's machine-translated English is the last resort. Use `--lang pl,en` to set your own order.

### Two ways to get captions
Captions come from [yt-dlp](https://github.com/yt-dlp/yt-dlp). If yt-dlp fails, the tool switches to [youtube-transcript-api](https://github.com/jdepoix/youtube-transcript-api) on its own.

### Keeps going when a Gemini model fails
Summaries try a list of Gemini models in order. If a model is overloaded, rate-limited, returns invalid JSON, can't be found or hits a network error, the next one takes over. Errors that a different model won't fix, such as a bad API key, stop the run right away.

### Structured output, every time
Gemini must reply in a fixed JSON schema, and the reply is checked with Pydantic before any Markdown is written. A malformed reply counts as a failure and passes the request to the next model.

### Check the transcript before you spend quota
Fetching and summarizing are two separate commands. `yt-transcript` never calls Gemini, so you can check the transcript first and only then spend your quota.

## How It Works

```text
YouTube URL ──▶ yt-transcript ──▶ transcriptions/<title>.txt ──▶ yt-summarize ──▶ summaries/<title>.md
                (yt-dlp, with                                    (Gemini, with
                 youtube-transcript-api fallback)                 model rotation)
```

1. **You paste a link.** `yt-transcript` reads the video ID, fetches the title, channel and duration, and picks the best caption track.
2. **It saves the transcript.** The file is plain text with a short header (`Title`, `Channel`, `URL`, `Duration`, `Captions`), named after the video title.
3. **Gemini summarizes it.** `yt-summarize` sends the transcript through the model rotation and checks the structured reply.
4. **You get Markdown.** The summary is printed to your terminal and saved to `summaries/`.

`yt-summarize` accepts any transcript file in this format, not only ones made by `yt-transcript`.

## Quick Start

You need **Python 3.14**, **[uv](https://docs.astral.sh/uv/)** and a **Gemini API key** ([get one here](https://aistudio.google.com/apikey)).

```sh
git clone https://github.com/unamatasanatarai/just-the-gist-youtube.git
cd just-the-gist-youtube
uv sync
cp .env.example .env    # then set GEMINI_API_KEY
```

### One command

```sh
./gist "https://youtu.be/dQw4w9WgXcQ"
./gist dQw4w9WgXcQ --model gemini-3.5-flash-lite   # extra options go to yt-summarize
```

The script fetches the transcript, then summarizes it. If fetching fails, it stops before calling Gemini.

### Step by step

```sh
$ uv run yt-transcript "https://youtu.be/dQw4w9WgXcQ?si=abc"
Fetching: Rick Astley - Never Gonna Give You Up (Official Video) (4K Remaster)
Captions: en (manual)
Saved transcriptions/rick-astley-never-gonna-give-you-up-official-video-4k-remaster.txt
Next: uv run yt-summarize transcriptions/rick-astley-never-gonna-give-you-up-official-video-4k-remaster.txt

$ uv run yt-summarize transcriptions/rick-astley-never-gonna-give-you-up-official-video-4k-remaster.txt
```

## Command Reference

### `yt-transcript`

```text
uv run yt-transcript VIDEO [--lang CODES] [--out-dir DIR] [-v]
```

| Option | Effect |
| --- | --- |
| `--lang pl,en` | Caption languages in priority order (replaces the default order) |
| `--out-dir DIR` | Where to save transcripts (default: `transcriptions`) |
| `-v`, `--verbose` | Show yt-dlp's own output and warnings |

Each run overwrites `transcriptions/<slug>.txt`. If the title gives an empty slug (for example, an all-emoji title), the video ID is used as the filename. A video with no captions ends with an error and no file is written.

### `yt-summarize`

```text
uv run yt-summarize TRANSCRIPT.txt [--model MODELS] [--out-dir DIR]
```

| Option | Effect |
| --- | --- |
| `--model a,b` | Gemini models to try, in order |
| `--out-dir DIR` | Where to save summaries (default: `summaries`) |

**Exit codes:** `0` success · `1` every model failed (each error is listed) or a fatal API error · `2` missing API key or unreadable transcript.

## Configuration

| Variable | Purpose |
| --- | --- |
| `GEMINI_API_KEY` | **Required.** Read from the environment or from `.env` in the current directory. A variable you have already exported takes precedence over `.env`. |
| `GEMINI_MODELS` | Optional comma-separated model list. `--model` takes precedence over it. |

The default rotation is `gemini-3.8-flash` → `gemini-3.6-flash` → `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite`.

## Testing

```sh
uv run pytest
```

116 tests cover URL parsing, caption choice, the yt-dlp fallback, file naming, model rotation and Markdown output. The tests never use the network: fakes stand in for yt-dlp, youtube-transcript-api and the Gemini client.
